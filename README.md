# ربات تلگرام هوش مصنوعی (AnyModel + Railway)

یک ربات تلگرام کامل با پایتون که از API [AnyModel](https://anymodel.org) استفاده می‌کند و شامل:

- 💬 چت هوشمند با حافظه مکالمه (چند مدل: GPT / Claude / Gemini / DeepSeek)
- 🎙 تبدیل پیام صوتی به متن و پاسخ صوتی (STT + TTS)
- 🖼 ساخت تصویر با هوش مصنوعی
- 📄📝📊📽 ساخت فایل PDF / Word / Excel / PowerPoint / TXT با محتوای تولیدشده توسط AI
- 🗜 ساخت فایل zip از چند فایل، و ویرایش فایل‌های zip (لیست، استخراج، افزودن، حذف)
- 🛠 پنل مدیریت کامل هم در خود تلگرام (دستورات ادمین) و هم یک پنل وب جداگانه (Flask + داشبورد)

آماده برای دیپلوی روی **Railway**.

---

## ۱. پیش‌نیازها

1. یک ربات تلگرام بساز: به [@BotFather](https://t.me/BotFather) پیام بده، `/newbot` بزن و توکن را بردار.
2. یک اکانت در [anymodel.org](https://anymodel.org) بساز و از داشبورد، API Key بگیر.
3. آیدی عددی تلگرام خودت را بگیر (مثلاً از [@userinfobot](https://t.me/userinfobot)) تا ادمین ربات باشی.

## ۲. تنظیم متغیرهای محیطی

فایل `.env.example` را کپی کن به `.env` و مقادیر را پر کن:

```
BOT_TOKEN=...............
ADMIN_IDS=آیدی_عددی_تو
ANYMODEL_API_KEY=...............
ANYMODEL_BASE_URL=https://anymodel.org/v1
ANYMODEL_CHAT_MODEL=gpt-5.6-sol
ANYMODEL_IMAGE_MODEL=gpt-image-1
ANYMODEL_STT_MODEL=whisper-1
ANYMODEL_TTS_MODEL=tts-1
ADMIN_USER=admin
ADMIN_PASS=یک-رمز-قوی
FLASK_SECRET_KEY=یک-متن-تصادفی-طولانی
```

> نکته مهم: نام دقیق مدل‌ها (برای چت/تصویر/STT/TTS) را از صفحه [مدل‌های AnyModel](https://anymodel.org/en/models) یا داشبورد اکانت خودت بردار، چون این نام‌ها ممکن است به‌مرور تغییر کنند. اگر مدلی که گذاشتی روی حسابت فعال نباشد، همان دستور با پیام خطا به کاربر اطلاع می‌دهد (چیزی کرش نمی‌کند).

## ۳. اجرای محلی (تست قبل از دیپلوی)

```bash
python -m venv .venv
source .venv/bin/activate      # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

- ربات با polling اجرا می‌شود.
- پنل وب روی `http://localhost:8080` بالا می‌آید (یوزر/پسورد همان `ADMIN_USER` / `ADMIN_PASS`).

## ۴. دیپلوی روی Railway

1. یک ریپازیتوری گیت‌هاب بساز و همه این فایل‌ها را داخلش push کن.
2. در [Railway](https://railway.app) پروژه جدید بساز → **Deploy from GitHub repo**.
3. در تب **Variables** همان مقادیر فایل `.env` را (بدون خود فایل `.env`) اضافه کن؛ Railway خودش متغیر `PORT` را ست می‌کند، نیازی به تعریف دستی نیست.
4. Railway به‌صورت خودکار از `railway.json` / `Procfile` استفاده کرده و `python main.py` را اجرا می‌کند.
5. بعد از دیپلوی، در تب **Settings → Networking** یک دامنه عمومی (Public Domain) بساز تا بتوانی پنل مدیریت وب را باز کنی: `https://<your-app>.up.railway.app`

### نکته دیسک/دیتابیس
دیتابیس SQLite در مسیر `data/bot.db` ذخیره می‌شود. روی Railway به‌صورت پیش‌فرض فایل‌سیستم موقتی(ephemeral) است، یعنی با هر دیپلوی جدید دیتا پاک می‌شود. اگر می‌خواهی داده‌ها (کاربران، آمار، تاریخچه) دائمی بمانند، از بخش **Volumes** ریلوی یک Volume بساز و آن را به مسیر `data/` وصل کن (Mount Path = `/app/data`).

## ۵. ربات کاملاً دکمه‌ای است (بدون دستور)

تنها دستور موجود `/start` است (چون تلگرام همیشه به یک نقطه‌ی شروع نیاز دارد). بعد از آن، همه‌چیز از طریق دکمه‌های ثابت پایین صفحه و دکمه‌های شیشه‌ای (inline) داخل پیام‌ها انجام می‌شود:

| دکمه | کاربرد |
|---|---|
| هر پیام متنی معمولی | چت با هوش مصنوعی |
| پیام صوتی 🎙 | تبدیل خودکار به متن + پاسخ هوش مصنوعی |
| 🖼 ساخت عکس | ربات توضیح تصویر رو می‌پرسه و عکس می‌سازه |
| 📄 ساخت فایل | انتخاب نوع فایل (PDF/Word/Excel/PowerPoint/TXT) با دکمه، بعد نوشتن موضوع |
| 🗜 ساخت Zip | فایل/عکس بفرست، بعد دکمه «پایان و دریافت آرشیو» یا «لغو» |
| ارسال یک فایل zip | دکمه‌های لیست محتوا / استخراج / افزودن فایل / حذف فایل |
| 🤖 انتخاب مدل | انتخاب مدل هوش مصنوعی از بین دکمه‌ها |
| 🔊 روشن/خاموش‌کردن پاسخ صوتی | تغییر وضعیت با یک لمس |
| 📈 آمار من | آمار استفاده شخصی |
| ♻️ پاک‌کردن حافظه | پاک‌کردن تاریخچه گفتگو |
| ℹ️ راهنما | نمایش دوباره راهنما |
| ❌ انصراف | لغو هر عملیات در حال انجام (ساخت عکس/فایل/zip و ...) |

برای ساخت PDF/Word با متن دقیق خودت (بدون دخالت AI)، وقتی ربات موضوع را می‌پرسد بنویس:
`raw: متن دقیق من اینجاست`

## ۶. پنل مدیریت داخل تلگرام (فقط برای آیدی‌های داخل `ADMIN_IDS`)

کاربرانی که آیدی عددی‌شان داخل `ADMIN_IDS` باشد، یک دکمه‌ی اضافه در منوی اصلی می‌بینند: **🛠 پنل مدیریت**. با زدن آن، یک منوی دکمه‌ای شیشه‌ای باز می‌شود:

- 📊 نمایش آمار کلی (تعداد کاربران، فعال امروز، پیام‌ها، تصاویر، فایل‌ها)
- 📢 پیام همگانی (متن را می‌نویسی و برای همه کاربران ارسال می‌شود)
- 👥 مدیریت کاربران (لیست کاربران با دکمه‌ی مسدودسازی/رفع مسدودیت و ارتقا/حذف دسترسی ادمین برای هرکدام، با صفحه‌بندی)
- 🤖 تنظیم مدل پیش‌فرض کل ربات
- 📝 تنظیم System Prompt پیش‌فرض

هیچ‌کدام از این کارها نیاز به تایپ دستور یا آیدی عددی ندارند؛ کاربران از لیست کاربران مستقیماً با دکمه انتخاب می‌شوند.

## ۷. پنل مدیریت وب

بعد از باز کردن دامنه ریلوی، وارد `/login` شو (لینک اصلی هم خودش ریدایرکت می‌کند):

- **داشبورد**: آمار کلی، آخرین کاربران، آخرین رویدادها
- **کاربران**: جستجو، مسدودسازی/رفع مسدودیت، ارتقا به ادمین
- **پیام همگانی**: ارسال پیام به همه کاربران با تاریخچه ارسال‌ها
- **تنظیمات**: تغییر مدل پیش‌فرض و system prompt
- **لاگ‌ها**: مشاهده خطاها و رویدادهای سیستم

> ارتباط بین پنل وب (Flask) و ربات (polling) از طریق یک صف داخل دیتابیس انجام می‌شود: وقتی از پنل پیام همگانی می‌فرستی، هر ۵ ثانیه یک Job داخل ربات صف را چک کرده و پیام‌ها را ارسال می‌کند.

## ۸. ساختار پروژه

```
main.py                 # نقطه شروع: بات + راه‌اندازی پنل وب
config.py                # خواندن متغیرهای محیطی
db.py                     # لایه دیتابیس SQLite (مشترک بین بات و پنل)
ai_client.py              # ارتباط با AnyModel (چت / تصویر / STT / TTS)
utils.py                  # ابزارهای کمکی (فونت فارسی، تقسیم پیام طولانی و ...)
handlers/
  menu.py                  # کنترل‌کننده اصلی منو/دکمه‌ها + پنل مدیریت تلگرامی
  keyboards.py              # تعریف تمام دکمه‌های ثابت و شیشه‌ای
  chat.py                  # چت اصلی با هوش مصنوعی
  voice.py                 # پیام صوتی -> متن -> پاسخ
  image.py                 # ساخت عکس
  files.py                 # ساخت PDF/Word/Excel/PowerPoint/TXT
  zip_tools.py              # ساخت zip و ویرایش فایل‌های zip
admin_panel/
  app.py                   # اپ Flask
  templates/               # صفحات HTML پنل
  static/style.css
```

## ۹. محدودیت‌ها و نکات

- رندر فارسی داخل PDF از فونت [Vazirmatn](https://github.com/rastikerdar/vazirmatn) استفاده می‌کند که در اولین اجرا به‌صورت خودکار دانلود می‌شود؛ اگر شبکه سرور به گیت‌هاب دسترسی نداشته باشد، PDF بدون گلیف فارسی (فقط لاتین) ساخته می‌شود — در این صورت فونت دلخواه را داخل `assets/fonts/Vazirmatn-Regular.ttf` قرار بده.
- نام دقیق مدل‌های تصویر/STT/TTS باید با آنچه در اکانت AnyModel شما فعال است مطابقت داشته باشد.
- برای جلوگیری از سوءاستفاده، حتماً `ADMIN_PASS` و `FLASK_SECRET_KEY` را مقادیر قوی و تصادفی بگذار.
